Why SignZero

Everything you need to get agreements signed.
Nothing you have to send elsewhere.

SignZero is built from standard Salesforce parts, so it fits the way your org already works.

Your data stays home

Every line of code that touches a document runs in your own org. No outside e-signature provider, which keeps security reviews and data-residency questions short.

No per-envelope fees

Send as many agreements as your org's email limits allow. SignZero is free and open source.

Built the Salesforce way

Records, Flow, reports, dashboards, permission sets and Experience Cloud. Admins configure it with clicks; developers extend it with an invocable action.

Evidence you can rely on

Every step goes into a hash-chained, append-only audit trail. Each envelope is sealed with a document hash and a Certificate of Completion.

Fast for signers

Your brand, your words

Security & evidence

An audit trail that shows if anyone touched it

Each event's hash covers its own details and the hash before it. Change or delete one event and the chain no longer verifies, and the Certificate of Completion says so.

  • Guest access, locked down. The signing site can call one Apex class, which checks the signer's token before doing anything.
  • Evidence can't be edited. Hashes, tokens, timestamps and signer status are blocked from manual edits in the UI, API and Data Loader.
  • Uploaded signatures stay private. An uploaded image only reaches Salesforce inside the signed PDF.
  • Optional PKI seal. Sign the document hash with an org certificate at sealing time.

Get started

Up and running in an afternoon

You need a Salesforce org with Experience Cloud.

  1. Create the signing siteAn Experience Cloud site at /esign where signers open their links.
  2. Deploy SignZeroOne sf project deploy from the repository.
  3. Assign permission setsSignZero_User for senders, SignZero_Guest for the site guest user.
  4. Publish and sendAdd your branding, publish the site, and click Send for Signature.

Read the technical guide →

# get the code
git clone https://github.com/haribaskarvr/SignZero.git
cd SignZero

# deploy to your org
sf project deploy start \
  --manifest manifest/package.xml \
  --target-org my-org

# give senders access
sf org assign permset \
  --name SignZero_User \
  --target-org my-org
